# AI Lab Checker

Объединённая версия: интерфейс Streamlit из UI-проекта и основная логика проверки из core.

## Запуск интерфейса

1. Установите зависимости: `pip install -r requirements.txt`
2. Убедитесь, что запущена Ollama и скачана модель, указанная в `core/config.py`.
3. Запустите: `streamlit run app.py`

## Пакетная проверка из папки works

Сохранён отдельный CLI-скрипт `check.py` из исходного MAIN-проекта.
Запуск: `python check.py`

Результаты пакетной проверки сохраняются в `results/`.
Интерфейсные критерии лабораторных находятся в `rubrics/`.
